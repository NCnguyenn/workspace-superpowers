# PI-Desktop native-host gate matrix

Campaign: `session-checklist-phase2-pi-desktop-20261003/phase4-readiness`  
Decision: **All eight gates are BLOCKED.**

## Status rule

`BLOCKED` means a required direct native trace, host artifact, permission observation, or independent review is unavailable. It is not a claim that PI-Desktop cannot support the capability in a future version. `UNAVAILABLE` names the absent evidence artifact; it does not become a pass/fail observation.

The historical PI-Desktop 0.15.9 host contract proves a limited `before_agent_start` prompt-application boundary. It does **not** prove a checklist event, native state owner, renderer, action callback, request scoping, or live model acceptance; its own result is `modelAcceptance: PENDING`. A read-only PI-Desktop 0.16.0 sidecar inspection now provides source-only evidence for the host-owned `TodoWrite` schema, agent-mode registration, host execution path, and lifecycle names in [09-todowrite-source.md](native-trace/09-todowrite-source.md). That evidence does not replace live traces or independent review.
