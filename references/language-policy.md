# Deliverable Language Policy

This policy selects the language of authored deliverables and keeps it separate from the language used for conversation. It applies to reports, theses, outlines, plans, documentation, skills, templates, table and figure labels, slide content, and generated or exported files.

## Default and explicit overrides

English is the default language for newly authored content and deliverables. Use another language only when the user explicitly requests it for the relevant deliverable. Reuse an already explicit, applicable instruction through revision and export; an override for one deliverable does not change the default for unrelated deliverables.

Do not infer deliverable language from the conversation, prompt, source document, template, or attachment language. A Vietnamese message that requests a report without naming a language requests an English report under this policy. Missing language information is resolved by the English default; do not ask a language question solely because it was omitted.

An explicit request to follow a language requirement in a supplied rubric is a language instruction. If an unadopted mandatory source requirement conflicts with the default, clarify that specific conflict before finalizing rather than silently switching languages.

## Conversation versus authored content

Chat explanations, questions, summaries, progress updates, and requirement analysis follow the language of the user's current message. Do not default that language to Vietnamese or any other language. Explain a necessary source term in the same sentence. Do not list unexplained keywords or provide a line-by-line translation.

An authored outline, report, plan, table, figure label, placeholder, exported file, or saved document remains in the locked deliverable language. A deliverable pasted into chat is still authored content, not a conversational update.

### No interleaved bilingual text

Do not interleave bilingual translations or explanations directly into chat blocks. Keep conversation cleanly in the current conversational language and keep the authored deliverable cleanly in its selected language. Do not alternate English paragraphs with Vietnamese explanations, or provide paired sentence-by-sentence translations, unless the user explicitly requests a bilingual deliverable.

A short framing sentence may use the conversation language. Preserve exact quotations, proper names, source titles, code, identifiers, and raw evidence in their original form when accuracy requires it; explain them in the selected deliverable language where useful.

## Protected source material, revisions, and exports

- A level-1 criterion heading preserves its exact `source_title`, including original language, under [outline structure](outline-structure.md). The English default does not authorize translating or paraphrasing it.
- Newly authored child headings, captions, placeholders, notes, and labels use the selected deliverable language.
- Preservation-only work does not authorize translation. If a request to keep supplied content unchanged conflicts with a requested language, ask about that conflict.
- Exporting a report changes format, not language. The source and export must use the same selected language.
- Record the selected language and explicit override, if any, in the brief. When no override exists, record English.

## Decision table

| User request or context | Required result |
|---|---|
| Vietnamese conversation; report language not specified | English report, including headings, captions, labels, and generated files. |
| Vietnamese input criterion; outline language not specified | Verbatim source criterion title at level 1; English newly authored child headings and outline content, without parallel translations. |
| Explicit request to write the report in Vietnamese | Vietnamese report, retained through revision and export. |
| Explicit request for another named language | That language for the named deliverable and its included labels. |
| Non-English source material without an instruction | English new content; preserve quotations and source titles accurately. |
| Existing instruction to preserve content during conversion | Preserve the content; do not infer permission to translate. |
| English report exported to PDF during a Vietnamese conversation | English PDF. |

This policy chooses language only. It does not approve scope, outline, evidence, citations, or file changes.
