# Workspace Superpowers 0.1.7-beta-update

This update clarifies the instruction pack while retaining the `0.1.7` base
version. It contains 24 skills, 12 roles, 15 shared references and 6 templates.

## Changes

- Make skill and role selection, inputs, procedures, boundaries and handoffs
  explicit. Brainstorming compares viable approaches using shared criteria and
  returns the user's choice to its caller.
- Preserve applicable outline approvals and explicit waivers throughout drafting
  and review. Authorized incomplete drafts retain neutral placeholders and
  `draft_incomplete`; required missing evidence still blocks affected new outlines.
- Distinguish reasoning review from formal machine verification, and keep native
  Word Equation fidelity separate from accepted limited handoffs.
- Align review severity, mathematics findings and progress values across their
  contracts and templates. Keep authored instructions in English and remove
  repeated wording without arbitrary length targets.
- Retain the built-in TodoWrite integration, plugin ID, permissions and all skill
  IDs. Historical traces and package records retain their original meaning.

## Package and installation

The PI-Desktop release assets are
`local.workspace-superpowers-0.1.7-beta-update.piplug`, its `.sha256` checksum
and `build-record.json`. Use PI-Desktop 0.16.0 or later and the native Plugins
install/update action. Preserve the existing enabled state and project scope;
reload the host and begin a fresh chat when testing the updated plugin.

To build locally:

```powershell
npm test
python scripts/test-package-pi.py
python scripts/package-pi.py --out dist/pi-0.1.7-beta-update
```

See [installation and rollback](../../adapters/pi/install.md).
